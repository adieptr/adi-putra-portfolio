Tentang saya

Saya adalah lulusan Diploma IV Teknik Informatika dengan minat besar pada pengembangan perangkat lunak, khususnya aplikasi berbasis web. Selama masa perkuliahan, saya mengerjakan berbagai proyek yang memberikan pengalaman sekitar 1,5 tahun dalam pengembangan website, termasuk sistem berbasis web terintegrasi Internet of Things (IoT) untuk klasifikasi kualitas telur serta aplikasi desktop untuk pengelolaan operasional toko kelontong. Saya memiliki keahlian pada pengembangan frontend dengan pemahaman backend yang baik, sehingga mampu membangun antarmuka yang responsif sekaligus mengimplementasikan logika aplikasi sesuai kebutuhan.

Selain kemampuan teknis, saya memiliki pengalaman sebagai Bendahara BOSP di SMP Nurul Huda II dan pernah menjalani magang sebagai Backend Developer di PT Wesclic Indonesia Neotech, Yogyakarta. Pengalaman tersebut mengasah kemampuan saya dalam administrasi, pengelolaan data, ketelitian, koordinasi, serta pengembangan sisi backend aplikasi. Saya memiliki semangat belajar tinggi, mudah beradaptasi, dan siap berkontribusi dalam pengembangan solusi digital maupun operasional organisasi.
